# 植物学家（Botanist）

这是一个基于 BaseLib 的《杀戮尖塔 2》角色 Mod，当前按 BaseLib 3.4.7 和 .NET 9 配置。


## 安装包

从 GitHub Releases 下载最新 `Botanist-v*.zip`，将其中的 `botanist` 文件夹解压到游戏的 `mods` 目录。安装包仅包含运行所需的三个文件：

```text
botanist/
├── botanist.dll
├── botanist.json
└── botanist.pck
```

安装前需要确保游戏为 v0.107.1，并已安装 BaseLib 3.4.7 或更高兼容版本。
