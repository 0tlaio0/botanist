# 植物学家新增卡牌概念设计指南

本文用于指导《杀戮尖塔 2》「植物学家」Mod 的新卡概念设计。这里讨论的是卡牌要表达什么体验、承担什么职责、与「种子与培育」如何互动，以及怎样判断一张卡是否值得进入后续制作。

本文只关注概念层，不展开具体制作细节。概念设计通过评审后，再进入后续流程。

## 1. 使用方式

本指南可以独立用于植物学家新卡的概念设计、数值预算和评审，不需要同时查阅其他文件。角色定位、核心机制、数值公式、文案要求和检查清单都已经包含在本文中。

建议按以下顺序使用：

1. 从角色体验基线确认这张卡是否符合植物学家的战斗方式。
2. 选择卡牌分类并填写概念立案表。
3. 使用第 7 章计算费用、基础价值、阶段修正和种子成长价值。
4. 检查播种、培育、成熟、满培养区和无种子状态。
5. 使用设计检查表完成评审，再进入后续制作。

如果设计需要改变核心规则，应先修改本指南中的对应规则，再继续设计单张卡。任何临时方案都不能绕过已经确认的原则。

## 2. 角色体验基线

植物学家是一名游历四方的植物学家。他依靠工具、技巧、研究和奇异植物处理战斗危机，而不是把所有问题都归结为植物爆发。

角色体验应保持四条主线：

- 中前期通过低费工具和技巧建立资源优势。
- 中后期通过种子成熟形成爆发、循环或持续引擎。
- 通过提前规划、选择元素和安排成熟顺序换取更高回报。
- 即使没有成熟种子，也能依靠工具与技巧完成防御和过渡。

因此，新卡不能只服务“最强状态”。它还必须回答：没有种子时是否有用，培养区已满时是否仍有意义，以及它是否让角色更像植物学家，而不是一个单纯堆放植物的战斗角色。

## 3. 概念设计原则

### 3.1 培育是核心，但不是唯一答案

种子与培育是植物学家的核心机制。大多数构筑支点最终都应与种子、元素、培养区或成熟效果产生联系。

但每张卡都强制围绕种子，会让构筑失去选择空间。工具、技巧和应急手段应当能够：

- 帮助没有种子或种子未成熟时渡过回合。
- 改变种子的成长速度、元素需求或成熟顺序。
- 提供抽牌、资源、控制和防守等基础能力。
- 为种子成熟创造机会，而不是提前替代成熟收益。

### 3.2 一张卡只承担一个主要职责

每张卡都应有明确的“一句话职责”，例如：

- 提供基础防守。
- 播种并等待成熟。
- 加速前 N 颗种子，N 由卡牌设计明确。
- 回收或复制成熟效果。
- 把元素使用转化为收益。
- 解决培养区满格时的取舍。
- 作为高稀有度构筑终端。

可以附带次要效果，但不能让一张卡同时完成攻击、防御、抽牌、回能和成长，并且每项都达到独立卡牌的水平。职责越集中，卡牌的构筑方向和数值边界越清楚。

### 3.3 元素是培育语言

地、火、水、风是种子成长所需的元素标签。元素的作用首先是把不同卡牌连接成可规划的成长路线。

元素可以有主题倾向，例如：

| 元素 | 常见主题方向 | 不应变成 |
| --- | --- | --- |
| 地 | 稳定、防守、培育、扎根 | 固定加格挡或固定加生命 |
| 火 | 激情、爆发、催熟、消耗 | 固定等于伤害属性 |
| 水 | 流动、恢复、抽牌、滋养 | 固定等于治疗或抽牌 |
| 风 | 移动、变化、控制、传播 | 固定等于速度或闪避 |
| 以太 | 万能、稀有、突破单一元素限制 | 常驻的第五种普通元素 |

这些方向服务于命名、插画和效果气质，不是新的硬性数值规则。设计元素需求时，应优先考虑玩家能否形成清晰的培育路线，而不是把某元素强行等同于某类效果。

### 3.4 成熟收益是核心，播种效果按平衡决定

种子牌必须有清晰的成熟效果。是否提供播种效果不是硬性要求，而应根据平衡决定：

- 没有播种效果时，种子是纯粹的前期投入，应通过更低需求、更顺畅的成熟路线或更强成熟收益补偿打出时的节奏损失。
- 有播种效果时，即时收益会占用卡牌强度，成熟需求或成熟效果应相应收敛。
- 无论有没有播种效果，成熟效果都应与元素需求、费用、稀有度和等待时间相匹配。

播种效果过强，成熟效果就没有存在感；成熟效果过强而没有代价，种子就会变成无脑循环。概念设计应明确说明：

- 玩家为什么愿意在本回合打出这张种子，即使它没有即时效果。
- 玩家为什么愿意等待它成熟。
- 等待期间承担了什么风险或机会成本。

### 3.5 收益必须能够解释

玩家应该能看懂一颗种子为什么成长、还缺什么、成熟后会得到什么，以及为什么此刻值得继续投入。

如果卡牌效果依赖隐藏顺序、难以察觉的条件或复杂连锁，设计时应先简化。神秘感可以来自植物和发现主题，但不能来自玩家看不懂结算。

### 3.6 种子作用范围由种植顺序决定

卡牌不应允许玩家从培养区中自由选择某一颗种子作为目标。这样会让卡牌变成随意点选，削弱种植顺序本身的意义。

作用于种子的卡牌应采用固定的位置范围：

- 前 N 颗种子。
- 后 N 颗种子。
- 培养区中的全部种子。
- 其他由明确、固定顺序决定的群体范围。

前 1 颗种子属于“前 N 颗”中 N 为 1 的情况，但不是让玩家自由挑选任意一颗。种植顺序是策略来源，玩家应通过安排打出顺序、影响前后位置或控制成熟时机来获得收益。

如果卡牌可以改变种子位置或顺序，必须是公开、可预期的位置操作，不能变成隐藏的任意目标选择。

### 3.7 获取渠道与奖励预算

卡牌的强度预算取决于获取渠道，而不是只看费用的稀有度。先判断卡牌来自哪里：

- 普通奖励、商店或卡牌池。
- 事件或特殊奖励中的一次选择。
- 初始牌转化、遗物给予或其他不可逆替换。
- 先古、Boss 级或每次通关只能获得一次的核心奖励。
- 由其他卡牌生成的衍生牌。

事件和先古奖励可以使用更高的单卡预算，因为玩家放弃了同节点的其他奖励。这个额外预算只能在以下条件成立时使用：

- 获取渠道确实稀有，不能进入普通奖励池。
- 同一节点存在有竞争力的替代奖励。
- 卡牌不能轻易复制、反复生成或无代价回到手牌。
- 高收益不会与低费用、低条件和跨战斗持续收益同时出现。

如果先古牌可以被普通生成、复制或稳定重复获得，它必须重新按普通卡预算计算，不能继续享受奖励级预算。

参考原版设计：破击和压制只有在“稀有先古选择、不可稳定复制”的前提下才成立；一旦能够稳定重复获得，它们就会明显越过普通卡模型。神化、撕咬等卡牌还必须按牌组规模或副本数量计算上限。

### 3.8 代价、条件与持续性

高收益必须对应至少一种可验证的代价或限制：

- 显式代价：失去生命、最大生命、费用、星费或其他特殊资源。
- 一次性限制：消耗、虚无、只能触发一次或不可升级。
- 持续代价：每回合失去属性、持续增加牌组负担或受到负面状态。
- 前置条件：需要充能球、奥斯提、空手牌、弃牌堆、指定牌型或种子位置。
- 对局条件：只能在长线战斗、Boss 战或特定阶段兑现收益。
- 规模限制：必须限制受影响卡牌数量、副本数量、种子数量或触发次数。

持续性越高，必须支付的代价越明确。参考原版：

- 至亮之焰用最大生命支付高额即时资源。
- 腐化和灵体通过消耗或虚无限制重复利用。
- 偏差认知和幽魂形态用持续衰减支付长期强度。
- 流星雨和封印王座分别用星费或星资源前置限制效果。
- 四重释放和守护者依赖充能球或奥斯提状态，不能只看最高伤害。

如果一张先古牌没有显式代价、持续代价、严格条件或不可复制性，就不应仅凭“先古”标签获得高额数值。

### 3.9 离群卡与卡组多样性

数值模型是卡组中心线，不是所有卡牌都必须落入的狭窄区间。卡组需要保留一小部分上侧离群卡和一部分下侧离群卡，避免所有卡牌在费用、收益、触发方式和风险上同质化。

离群卡应满足以下条件：

- 上侧离群卡必须有低频条件、真实代价、稀有获取或明显的构筑要求。
- 下侧离群卡必须在稳定性、操作空间、牌序调整或特定体系中有不可替代的作用。
- 离群卡不能成为大多数牌组的固定最优解，也不能挤占普通牌的职责。
- 每轮内容评审应同时检查“所有卡是否过于接近模型”和“离群卡是否越界过多”。

原版《杀戮尖塔 2》的常规回合通常以 3 点能量为环境基准。4 费以上、高额 X 费、同时使用多种元素或多个前置条件，都属于低频高投入场景，应作为收益上限评估，而不是按每回合都能稳定打出的标准卡比较。

这类高上限卡允许在条件完全满足时明显超过同费模型，但必须记录：

- 达到上限需要多少能量、手牌和前置资源。
- 在当前 3 能量环境中，玩家多常能真正达到上限。
- 达到上限后是否还能继续打出其他关键牌。
- 没有达到条件时，卡牌是否仍有可接受的保底作用。

## 4. 卡牌分类

新卡立案时应先选择主要分类。分类可以重叠，但必须有一个主要归属。

### 4.1 种子与植物

重点表达植物本身的特征，包括现实植物、高塔植物、幻想植物和跨界致敬植物。

植物类设计的核心要求是名称、形象、元素需求和成熟效果之间保持一致意象；如果存在播种效果，也应纳入同一套意象。例如：

- 向日葵偏向稳定防守与积累。
- 虚凰草偏向重生、短暂无敌和蜕变。
- 带刺植物偏向反击或持续伤害。
- 食虫植物偏向吞噬、削弱或对单点目标施压。

不能只是因为某张原版卡数值合适，就换一个植物名字套用。植物特征必须真正参与效果设计。

### 4.2 工具

工具用于处理具体问题，例如开掘、移植、修剪、采集、测量、保存和培育。

工具牌通常不应成为主要成长目标，而应帮助玩家：

- 扩大或调整培养条件。
- 处理培养区满格。
- 改变种子的前后顺序或位置段，但不能指定任意某一颗种子。
- 改善元素供给。
- 在缺少某类种子时维持基本战斗力。

工具牌的价值应来自操作感，而不是单纯比普通攻击或防御更高效。

### 4.3 技巧与技术

技巧牌体现旅行经验和植物学知识，例如野外调查、组织培养、轮作、应急处理和生态观察。

技巧牌适合承担：

- 抽牌与筛选。
- 临时适应不同元素。
- 改变播种或成熟顺序。
- 将已有资源转化为防守或节奏。
- 为特定构筑提供操作上限。

技巧牌不应成为只有数值、没有决策的“大号基础牌”。

### 4.4 混合与终端卡

混合牌把成熟植物、工具或技巧组合起来，作为中高稀有度的构筑支点。

终端卡应要求玩家已经完成某种准备，例如：

- 培养区存在指定数量或元素组合的种子。
- 本回合使用过一定数量的不同元素。
- 曾让种子成熟、离开培养区或复制过成熟效果。
- 为后续回合建立持续生成或循环。

终端卡的强度来自条件达成的规划成果，而不是无条件超过普通卡。

### 4.5 初始牌与先古牌

初始牌负责在新局前几场战斗中稳定展示角色基础玩法。初始攻击和初始防御可以朴素，但不能与种子、元素或基础资源完全无关。

先古牌是少量、明确、带代价的强化方向。先古不是“更稀有的普通卡”，也不应只是把一张已有卡的所有限制删除。

### 4.6 衍生牌与成本归属

衍生牌的成本同时包括自身成本和生成来源成本：

```text
衍生卡成本 = 衍生卡自身成本 + 生成它的原卡成本
```

如果一张原卡生成多张衍生牌，每张衍生牌都追加该原卡的完整成本。若衍生牌继续生成新的衍生牌，生成链逐层累加所有来源成本。

原卡的价值额外包含所生成衍生卡价值的 1/5：

```text
原卡价值 = 原卡自身价值 + 1/5 × 所生成衍生卡价值总和
```

计算规则：

- 一张原卡生成多张衍生牌时，使用这些衍生牌价值的总和，每张分别计算 1/5。
- 衍生牌继续生成其他牌时，先按相同规则计算该衍生牌的完整价值，再计入上一层的 1/5。
- 非卡牌来源按等效原卡成本处理，例如遗物或能力提供的衍生牌，应使用该来源的等效费用。
- 循环或互相生成必须设置生成上限，并按每一轮实际生成数量累加成本与价值。

## 5. 种子概念规范

### 5.1 种子不是独立卡牌类型

种子是卡牌的身份与玩法标签，不是新的攻击、技能、能力或状态分类。

一张种子仍然应按照其主要效果表现为攻击、技能、能力、状态或诅咒。玩家看到的卡牌类型应反映它此刻做什么，而不是因为“所有种子都必须长得一样”。

### 5.2 打出效果与成熟效果

每张种子都必须明确成熟效果。播种效果是可选设计，应根据即时收益与延迟收益的平衡决定：

| 阶段 | 设计要求 |
| --- | --- |
| 打出时（可选） | 如果存在播种效果，应较弱、稳定，能解决当前回合的一部分问题 |
| 培养中 | 明确需要哪些元素、还缺多少、是否容易被继续培养 |
| 成熟时 | 明显更强，是玩家等待和投入元素的主要回报 |
| 离开培养区后 | 说明是否进入弃牌堆、是否触发其他效果、是否存在例外 |

没有播种效果的种子必须在卡面上直接表现为投资牌，不能故意隐藏“本回合没有即时收益”这一事实。它通常需要更容易培养、较强的成熟回报，或能与现有路线紧密衔接。

存在播种效果时，播种和成熟不能只是同一效果的大小版本。理想情况下，两者应体现植物从播种到成熟的变化。

### 5.3 元素需求

每张种子拥有 1 至 3 种不同元素需求，总需求建议为 2 至 8 点。

设计时遵循以下原则：

- 单一元素需求适合清晰、稳定的入门种子。
- 双元素需求适合形成组合路线，并表现植物成长需要多种条件。
- 三元素需求适合高稀有度或强成熟效果，但不应频繁出现。
- 同一种元素不应在一张种子中重复计数，避免卡面和实际成长难以理解。
- 需求越高，越应控制播种效果等即时收益，不能同时拥有轻松播种和低成本高强度成熟。

### 5.4 种子不能自我完成

打出带元素的卡牌时，该元素只作用于培养区中已经存在的种子。新打出的种子不会用自己的元素给自己扣点。

这条规则保证种子的成长依赖牌序和提前准备，而不是打出后自动完成一部分需求。

### 5.5 即时收益与成熟收益不能无限叠加

单张种子不得同时提供高额即时伤害、高额防御和低成本成熟。种子可以偏攻击、偏防御、偏功能或偏成长，但不能在所有维度都优于同费普通卡。

没有播种效果也不能成为成熟效果超模的理由。延迟是代价，但仍需匹配元素需求、费用、稀有度和构筑成本。

高额成熟收益应至少满足以下一项条件：

- 元素需求较高。
- 播种效果较弱或没有播种效果。
- 培养位置紧张。
- 成熟需要特定牌序或构筑支持。
- 成熟后存在明确代价或延迟。

## 6. 培养区与万能元素

### 6.1 培养区是有限空间

培养区初始为 3 格，最多可扩展到 10 格。位置数量是角色规划的一部分，不能被视为背景界面。

培养区满格时应形成明确取舍：

- 如果新种子有播种效果，仍完整结算该效果。
- 新种子不会进入培养区，而是直接离开培育流程。
- 玩家需要在等待旧种子成熟和接受新种子本回合收益之间做选择。

扩容可以存在，但必须是少量、有代价的专门设计。新卡不能无条件消除培养区上限，也不能让玩家忽略位置管理。

### 6.2 培育触发统一

首版统一为：打出带元素标签的卡牌时，培养区中需要该元素的种子各减少 1 点对应计数。

固定规则如下：

- 一张牌只触发一次培育。
- 不额外增加回合开始或回合结束的自动扣点。
- 同一张牌可以同时推动多颗符合条件的种子。
- 作用于种子的效果只能按前 N 颗、后 N 颗、全体或其他固定顺序范围结算。
- 不允许玩家自由选择培养区中的任意一颗种子。
- 所需的全部计数归零后立即成熟。
- 多颗种子同时成熟时，按培养区顺序或卡牌明确说明的顺序结算。

新卡如果有额外培育效果，必须在卡面上明确说明，不能依赖玩家猜测。

### 6.3 万能元素

万能元素由初始遗物「异界烙印」在每场战斗开始时提供，表现为消耗牌「以太」。

打出万能元素后，培养区中所有种子的每种所需元素计数各减少 1，最低为 0。它应保持稀有、明确且具有强突破感，不能变成普通元素牌或无限循环的默认燃料。

### 6.4 战斗结束与跨战斗保留

战斗结束时，培养区中所有未成熟种子都会离开。跨战斗保留必须由遗物或卡牌文字明确声明，不能作为默认行为。

如果设计希望某颗种子例外保留，应把它作为高稀有度、有代价的特殊机制单独评审。

## 7. 数值设计指导与内容结构

### 7.1 数值模型与使用原则

本章完整给出概念评审所需的数值模型，不依赖其他数值文档。常数、费用预算、稀有度倍率、阶段修正和种子成长评分都应在本文内直接使用。

不存在一张卡牌的绝对分数。项目采用三层估值思路：

```text
总价值 = 基础效果价值 × 时间与语境修正
       + 协同价值
       - 卡组密度成本
       - 机会成本
```

公式用于第一轮平衡筛选，不能代替实机模拟和数据回归。同一张卡在第一层、第三层、普通战斗、Boss 战和不同构筑中的价值并不相同。

### 7.2 总体内容结构

角色目标约为 85 张专属卡牌，允许小幅调整。总体比例目标为：

- 攻击牌、技能牌、能力牌约为 2:4:3。
- 普通、罕见、稀有约为 2:4:3。
- 先古牌保持 2 张左右，并围绕指定先古来源设计。

先根据结构缺口确定卡牌分类，再进行数值评分。内容比例不能成为超出预算的理由。

### 7.3 资源成本与基础评分

先建立资源兑换关系：

```text
1 张牌位 ≈ 0.5 至 0.7 点能量
默认取 0.6
C = 能量费用 + 0.6
```

因此，不同费用卡的相对成本为：

| 费用 | 相对成本 C | 相对 1 费卡成本 |
| ---: | ---: | ---: |
| 0 费 | 0.6 | 0.375 |
| 1 费 | 1.6 | 1.000 |
| 2 费 | 2.6 | 1.625 |
| 3 费 | 3.6 | 2.250 |

高费牌的总效果可以更大，但单位能量效率应逐步下降。2 费不是 1 费效果的两倍，3 费也不是三倍。

基础价值使用以下评分：

```text
R = 伤害
  + 0.85 × 格挡
  + 1.50 × 易伤层数修正
  + 1.20 × 虚弱层数修正
  + 2.00 × 力量或敏捷的预期触发价值
  + 抽牌价值
  + 3.50 × 立即获得的能量
  + S
```

抽牌价值单独折算：

```text
抽牌价值 = 1.8 × max(0, 抽牌数 - 1) + 0.5 × 抽牌数
```

`S` 表示特殊机制、成长、消耗、检索、条件收益和其他无法直接归入基础单位的效果。

基础效率为：

```text
P = R / C
```

先计算 `R` 和 `P`，再依次加入稀有度、阶段、敌人、卡组需求、协同和重复惩罚。不能只凭原始 `R` 判断最终强度。

### 7.4 基础锚点与费用预算

项目使用以下基础锚点：

| 锚点 | 数值 |
| --- | --- |
| 基础攻击 | 1 费造成 6 点伤害 |
| 基础防御 | 1 费获得 5 点格挡 |
| 基础过牌 | 1 费抽 2 张 |
| 条件型零费 | 0 费造成 3 点伤害并施加 1 层虚弱 |

按 `C` 和基础公式计算：

```text
1 费 6 点伤害：C = 1.6，R = 6，P = 3.75
1 费 5 点格挡：C = 1.6，R = 4.25，P = 2.66
```

攻击效率高于防御效率是合理的。伤害推进战斗结束，格挡只避免损失，而且可能因敌人不攻击而浪费。不能为了追求相同 `P`，强行把攻击和防御做成同一数值。

以普通攻击锚点为核心，普通、无条件、无副作用卡牌的基础预算为：

| 费用 | 基础效果预算 |
| ---: | ---: |
| 0 费 | 约 2 至 3 点 |
| 1 费 | 约 5 至 7 点 |
| 2 费 | 约 9 至 12 点 |
| 3 费 | 约 13 至 18 点 |

稀有度、条件、成长和构筑要求可以突破基础预算，但必须支付相应代价。

常规环境按每回合约 3 点能量评估。4 费以上、高 X 费和多元素组合属于低频上限区：

- 普通卡主要按常态费用和稳定收益评价。
- 低频高上限卡必须同时记录常态区间、触发区间和理论上限。
- X 费牌按预期投入计算中心值，再单独计算高投入上限，不能只取最大值或只取最低值。
- 上限越高，达到上限所需的能量、牌序和前置资源越多；如果这些条件在当前环境里很常见，则必须重新降低上限。

### 7.5 效果单位价值

计算 `R` 时使用以下单位：

| 效果 | 第一版价值 |
| --- | ---: |
| 1 点伤害 | 1.0 |
| 1 点格挡 | 0.8 至 0.9 |
| 1 层虚弱 | 1.2 至 1.8 |
| 1 层易伤 | 1.5 至 2.2 |
| 抽 1 张 | 约 0.5 |
| 抽 2 张 | 约 2.8 |
| 抽 3 张 | 约 5.1 |
| 立即获得 1 点能量 | 3.5 |

群体伤害应按预期命中数计算，并乘以命中稳定性。随机伤害、分散伤害和多段伤害不能只按理论总伤害估值，还要计算力量、易伤和逐次触发协同。

X 费伤害按预期投入 1.5 至 2 点能量估值，不按最大投入估值。条件格挡按触发概率而不是理论最大值估值。

虚弱和易伤的价值取决于后续攻击次数、命中概率和生效回合数：

```text
易伤价值 ≈ 后续伤害增量 × 命中概率 × 生效回合数
虚弱价值 ≈ 被减少的敌方伤害 × 命中概率 × 生效回合数
```

力量或敏捷按预期触发次数计算：

```text
成长价值 = 每次触发收益 × 预计剩余触发次数 × 实现概率
```

永久成长牌通常是早期投资、后期兑现，不能把未来理论收益直接视为当前的完整收益。

### 7.6 稀有度预算

稀有度提高卡牌的上限、构筑潜力或不可替代性，而不是把所有数值简单乘以更高倍数：

| 卡牌类型 | 起始倍率区间 |
| --- | ---: |
| 普通卡 | 0.90 至 1.05 |
| 罕见卡 | 1.00 至 1.15 |
| 稀有卡 | 1.15 至 1.35 |
| 核心构筑卡 | 1.25 至 1.50 |
| 高费爆发卡 | 1.30 至 1.60 |

核心构筑卡至少满足一个限制：

- 需要特定牌或遗物配合。
- 启动速度慢。
- 面对部分敌人无效。
- 消耗牌组资源或生命。
- 需要较长牌组循环。
- 占用关键牌位或关键费用。

稀有卡在无配合时也很强、有配合时又极强，通常说明数值或稳定性过高。不能只用稀有度解释超模效果。

### 7.7 阶段与语境修正

基础评分完成后，按阶段修正：

| 阶段 | 伤害 | 格挡 | 成长 | 过牌和费用引擎 |
| --- | ---: | ---: | ---: | ---: |
| 第一层 | 即时 1.20 至 1.40 | 0.90 至 1.05 | 0.70 至 0.90 | 主要作为过渡 |
| 第二层 | 即时 1.00 至 1.15 | 1.00 至 1.15 | 1.00 至 1.20 | 1.10 至 1.30 |
| 第三层及终局 | 即时 0.85 至 1.05 | 单次 0.85 至 1.00 | 1.20 至 1.45 | 1.20 至 1.45 |

第一层的高费组合件使用 0.60 至 0.85；第一层群体伤害使用 1.00 至 1.20，第二层群体伤害使用 1.00 至 1.25。

第一层更重视低费、即时和稳定；第三层更重视上限、稳定性、循环速度和应对 Boss 的能力。只解决普通战斗的卡在终局应下降到 0.65 至 0.85。

最终估值使用以下语境修正：

```text
最终价值 = 基础 R
         × 阶段倍率
         × 敌人倍率
         × 卡组需求倍率
         × 稀有度倍率
         × 获取预算系数
         × 持续倍率
         + 规模价值
         - 显式代价
         - 机会成本
         - 可靠性惩罚
         - 重复惩罚
         - 密度惩罚
```

敌人类型会改变效果价值：多敌人提高群体伤害，高频攻击提高格挡和虚弱，长线 Boss 提高永久成长和循环价值，速杀节点提高即时伤害和零费牌价值。

### 7.8 协同、重复与边际价值

同类卡数量增加后，边际价值下降：

```text
边际价值 = 基础价值 / (1 + 同类牌数量 × 重叠系数)
```

推荐的重叠系数为：

| 卡牌类型 | 重叠系数 |
| --- | ---: |
| 普通输出牌 | 0.20 至 0.35 |
| 普通防御牌 | 0.20 至 0.35 |
| 关键启动牌 | 0.40 至 0.60 |
| 独特功能牌 | 0.05 至 0.15 |

协同价值不能因为存在理论组合就全额计算：

```text
协同价值 = 组合收益 × 抽到概率 × 启动成功率
```

如果一张牌必须先抽到另外两张牌才能兑现价值，除非它有检索或保留能力，否则平均价值必须显著下降。

衍生牌成本追加生成来源：

```text
C_token = C_token_self + C_source
```

生成来源的价值包含衍生牌价值的 1/5：

```text
V_source = V_source_self + 0.2 × Σ V_token
```

多张衍生牌按价值总和计算。生成链逐层应用这两个公式，不能只计算直接生成的最后一张牌。

### 7.9 种子与培育数值

种子没有独立于主公式的第二套数值体系。其数值仍使用 `C、R、P`，但要单独计算：

- 打出时的播种效果。
- 成熟效果的预期收益。
- 从播种到成熟所需的回合和元素牌数量。
- 实现该成长路线所需的位置和牌序。
- 与其他种子的协同、重复惩罚和位置竞争。

项目要求每张种子拥有 1 至 3 种不同元素需求，总需求为 2 至 8 点。需求数量和总量用于描述成长路线的复杂度，不能直接当作固定强度倍率。

| 需求档位 | 元素总需求 | 数值处理 |
| --- | ---: | --- |
| 入门种 | 2 至 3 点 | 播种效果可以接近同费普通牌；成熟效果按较低 `S` 计算 |
| 核心种 | 4 至 5 点 | 播种、成熟或二者共同承担预算；必须计入实现概率和延迟 |
| 终端种 | 6 至 8 点 | 主要价值来自较高 `S`；播种效果通常较低或不存在，并必须检查最佳牌序上限 |

成熟效果使用成长价值方法计算：

```text
成熟价值 = 单次成熟收益 × 实现概率 × 时机折现 × 边际价值
```

没有播种效果时，不套用固定的百分比补偿。它意味着打出回合的即时 `R` 较低，需要通过更低的成长门槛、更高的成熟收益、更低的费用或其他可量化因素重新回到合理预算。不能同时降低需求、降低费用并提高成熟收益。

培育干预效果按“改变了多少颗种子的预期成熟价值”计算，不按个别卡牌样例的价值估算：

```text
培育干预价值 = 受影响种子的成熟价值增量
             × 培养区中存在相应种子的概率
             × 位置或顺序可达成率
```

前 N 颗、后 N 颗和全体种子的影响范围不同，必须分别计算。全体种子减少需求会随培养区数量放大，要检查 3 颗以上种子同时存在时的上限。

### 7.10 升级设计

升级分为四类：

1. 数值升级：提高伤害、格挡或效果数值，适合普通牌。
2. 效率升级：降低费用，适合高费牌或启动牌。
3. 功能升级：增加抽牌、消耗、目标数或保留。
4. 条件升级：移除限制、降低代价或扩大触发范围。

推荐升级价值为：

| 卡牌 | 升级价值 |
| --- | ---: |
| 普通攻击牌 | 基础效果的 25% 至 40% |
| 普通防御牌 | 基础效果的 25% 至 45% |
| 关键启动牌 | 优先增加功能 |
| 稀有核心牌 | 可以改变构筑方向，但不得同时降低成本、增加效果并移除条件 |

升级后选取率超过 80%，通常说明基础牌太弱、升级收益过大、费用段缺少替代品，或休息点选择被单一升级垄断。

### 7.11 整局成长预算

一次成功通关可以按约 100 点成长价值估算：

| 收益来源 | 次数 | 单次价值 | 合计 |
| --- | ---: | ---: | ---: |
| 精英 | 10 | 2.5 | 25 |
| 升级 | 8 | 2.5 | 20 |
| 普通战斗 | 15 | 1.5 | 22.5 |
| Boss 宝箱 | 2 | 5 | 10 |
| 中途宝箱 | 3 | 3 | 9 |
| 问号事件 | 6 | 0.75 | 4.5 |
| 商店 | 3 | 3 | 9 |
| 总计 |  |  | 约 100 |

该预算用于检查经济是否闭环：

- 普通战斗卡牌价值普遍过高，玩家会迅速超过成长曲线。
- 精英奖励过高，最优策略会偏向刷精英。
- 升级价值过低，休息点会全部转向回血。
- 商店价值过低，金币会失去构筑意义。

卡牌数值必须和敌人成长、房间收益、遗物强度及升级系统一起检查。

### 7.12 数据校准与失衡信号

第一版公式完成后，需要观察：

- 被提供后的选取率。
- 选中后的胜率提升。
- 推进层数。
- 不同角色和难度下的稳定性。
- 升级优先率和移除优先率。
- 与特定体系的组合选取率。
- 跳过该卡的频率。

胜率分析至少要控制层数、当前血量比例、难度、遗物数量、角色、牌组规模和同类卡数量。不能把高水平玩家更会选强卡的现象误算成卡牌强度。

出现以下信号时应优先降低效率，再考虑增加限制：

- 普通牌在所有体系中的选取率都超过 70%。
- 稀有牌在无配合时也几乎必选。
- 一张牌同时提供高伤害、高防御和高过牌。
- 0 费牌可以反复循环且不消耗。
- 升级降低费用后，效果还大幅增加。
- 卡牌的唯一代价只是文字描述，不影响实际操作。
- 第二份和第三份同名牌几乎没有边际损失。
- 商店、事件和普通战斗都能稳定提供同一类顶级奖励。

直接砍数值往往会让卡变得无趣。通常更好的做法是增加启动成本、降低稳定性或收紧触发条件。

### 7.13 获取、代价与持续性评分

获取预算系数只有在卡牌来源确实受限时才使用：

| 获取渠道 | 获取预算系数 |
| --- | ---: |
| 普通卡牌池、稳定生成 | 1.00 |
| 事件、商店或稀有奖励选择 | 1.00 至 1.15 |
| 初始牌转化或其他不可逆替换 | 1.05 至 1.25 |
| 先古、Boss 级或一次通关中的独占选择 | 1.15 至 1.60 |

获取预算系数是上限，不是免费加强。它必须同时满足不可自由复制、存在替代奖励且来源稳定可识别。先古牌进入普通生成池或被稳定复制后，系数立即回到 1.00。

显式代价和机会成本都应折算成同一套 `R` 单位：

```text
显式代价 = 生命、最大生命、特殊资源、消耗、虚无和其他直接损失
机会成本 = 放弃的替代奖励 + 不可逆替换损失 + 稀有获取机会
可靠性惩罚 = 未满足前置条件、抽不到关键牌或触发失败的概率损失
```

项目还没有定义换算的资源必须先在指南中补充单位，不能按 0 成本处理。星费、充能球、奥斯提、特殊牌型或专属状态都属于前置资源，必须先确定其 `R` 价值。

持续倍率按收益持续时间计算：

| 持续范围 | 评分方式 |
| --- | --- |
| 只影响当前结算 | 1.00 |
| 影响本回合后续 | 按本回合仍能兑现的行动数修正 |
| 持续整场战斗 | 按预计剩余回合数和启动时间计算 |
| 跨战斗或永久保留 | 作为整局成长价值单独评估，不使用普通卡预算 |

规模价值按预期实际数量计算，而不是理论最大值：

```text
规模价值 = 单次收益 × 实际影响数量 × 实现概率
```

全牌组升级、全部种子、所有同名卡和可无限增长的伤害都必须设置明确上限。未设上限的卡牌要按最佳情况、平均情况和上限分别评审。

### 7.14 数值评审流程

每张卡至少回答：

1. 它消耗多少能量和牌位？
2. 它的即时效果 `R` 是多少？
3. 它需要几个回合回本？
4. 它在第一、第二、第三层分别有多强？
5. 它需要什么牌或遗物配合？
6. 组合收益和抽到组合的概率是多少？
7. 同类牌已有几张时，它的边际价值下降多少？
8. 升级增加的是数值、效率、功能还是条件放宽？
9. 它的代价是否真实影响牌组和操作？
10. 数据上是否出现过高的选取率、升级率或胜率提升？

数值评审顺序固定为：

```text
资源锚点
  → 基础效果评分 R
  → 费用成本 C 与基础效率 P
  → 稀有度预算
  → 获取渠道与机会成本
  → 阶段、敌人和卡组语境
  → 显式代价、持续时间和规模上限
  → 协同、重复和密度惩罚
  → 种子成长与培育干预
  → 升级价值
  → 模拟测试
  → 真实数据回归
  → 小步调整
```

## 8. 主题与叙事一致性

每张卡都应通过以下维度表达同一个概念：

- 卡名。
- 卡面形象。
- 元素标签。
- 打出时的播种效果（若有）。
- 成长需求。
- 成熟效果。
- 稀有度与获取方式。

例如，一张以古树为名的种子却造成短时爆发火焰伤害，即使数值平衡，也会削弱角色的植物学主题。跨界或幻想植物可以夸张，但内部逻辑要说得通。

先古牌还应有“失落知识、古老生命或规则级发现”的叙事重量，不应只是普通植物换了更亮的颜色。

## 9. 卡面文案原则

卡面文案必须明确区分效果发生的时间点。

| 时间点 | 推荐表达 |
| --- | --- |
| 打出时的播种效果（若有） | 直接描述即时效果，必要时写“打出时……”；没有播种效果时不要虚构该阶段 |
| 培养中 | 明确写“培养中的种子”“所需元素”或“剩余计数” |
| 成熟时 | 使用统一关键词「成长」，例如「成长：获得 1 层无实体」 |
| 离开培养区 | 明确写“离开培养区时”“未成熟时”或“进入弃牌堆” |

文案应遵守以下要求：

- 统一使用「打出时的播种效果（若有）」「培养中」「成长」「成熟时」「离开培养区后」等术语。
- 不要用「成长计数减少 1」代替具体元素含义。
- 作用于全部需求时，写清“每种所需元素计数各减少 1”。
- 作用于前 N 颗或后 N 颗种子时，明确写出 N 和方向，不能写成“选择一颗种子”。
- 播种效果（若有）、成熟效果和升级变化必须能在卡面上分别看懂。
- 卡名、机制名称和能力名称不能在不同卡牌中随意更换说法。

如果一句文案需要额外三步解释才能理解，应优先简化设计，而不是继续堆叠说明。

## 11. 评审流程

### 第一步：确认设计前提

检查卡牌是否符合本指南中的角色定位、种子机制和内容结构。与已有规则冲突时，先调整设计，不要为单张卡临时修改整体规则。

### 第二步：确认职责

用一句话说明这张卡的职责。如果不能在不使用“很强”“很全面”“什么都有一点”的情况下说明，它通常还没有设计清楚。

### 第三步：确认培育闭环

检查种子在空培养区、满培养区、已有其他种子、元素不足和战斗结束时的表现。任何例外都必须写进卡面。

### 第四步：检查平衡

按第 7 章计算该卡的 `C、R、P`，再加入稀有度、阶段、敌人、卡组需求、协同和重复惩罚。重点检查种子的成长价值是否按实现概率和时机折现，而不是按成熟后的理论上限直接计分。

### 第五步：检查主题与文案

确认卡名、形象、元素、效果和文案讲的是同一件事。删去无法被玩家实际感知的背景设定。

### 第六步：记录评审结论

每张卡最终应得到以下结论之一：

- 通过，可以进入后续制作。
- 有条件通过，需修改指定内容后复审。
- 暂时保留，当前不适合加入内容结构。
- 否决，与核心机制、角色定位或已有卡牌冲突。

## 12. 设计检查表

- [ ] 卡牌符合植物学家“工具、技巧、植物与规划”的角色定位。
- [ ] 卡牌有一个清晰、单一的主要职责。
- [ ] 卡牌补足的内容方向与当前结构缺口一致。
- [ ] 元素服务于培育路线，没有被当成伤害属性或能量色。
- [ ] 种子具有明确的成熟效果；播种效果按平衡决定，不把可选设计写成硬性要求。
- [ ] 没有播种效果时，通过需求、成熟收益或路线衔接补偿打出时的节奏损失。
- [ ] 伤害、格挡、状态、抽牌和能量已经按第 7 章的效果单位换算为 `R`，并计算了资源成本 `C` 和基础效率 `P`。
- [ ] 稀有度、阶段、敌人类型和卡组需求已经作为修正倍率考虑，没有只看基础 `R`。
- [ ] 卡牌在常态区间与低频上限区间分别评价，没有用理论最大值代替平均表现。
- [ ] 4 费以上、X 费高投入、多元素或复杂前置条件已经按当前 3 能量环境计算触发频率。
- [ ] 卡组保留了少量合理上侧离群和下侧离群卡，没有强制所有卡牌贴近同一强度中线。
- [ ] 获取渠道、替代奖励、机会成本和不可复制性能够支撑所使用的获取预算系数。
- [ ] 生命、最大生命、星费和其他特殊资源已经换算为 `R`，没有按 0 成本处理。
- [ ] 持续范围和规模上限已经按实际触发次数与平均影响数量计算。
- [ ] 同名卡和同类卡增加时，边际价值下降已经计入。
- [ ] 卡牌总收益处于对应费用和稀有度的预算区间，超出的部分有明确条件或代价。
- [ ] 衍生卡成本追加了生成来源成本，生成链中的成本已逐层累加。
- [ ] 原卡价值额外计入所生成衍生卡价值总和的 1/5。
- [ ] 作用于种子的效果使用前 N 颗、后 N 颗、全体或其他固定顺序范围，不要求玩家选择任意一颗。
- [ ] 种子的种植顺序在设计中具有实际策略意义。
- [ ] 种子拥有 1 至 3 种不同元素需求，总需求处于合理范围。
- [ ] 种子的需求、预计成熟时间和成熟收益符合入门、核心或终端档位。
- [ ] 无播种效果时只通过需求、路线、成熟收益或费用中的一项主要方向补偿，没有同时获得多项上限收益。
- [ ] 种子不会用自己的元素给自己扣点。
- [ ] 单张种子没有同时提供高额即时伤害、高额防御和低成本成熟。
- [ ] 没有成熟种子时，角色仍能通过工具和技巧完成过渡。
- [ ] 培养区满格时存在明确取舍，而不是新卡无条件消除限制。
- [ ] 万能元素仍然稀有、明确且不可被普通卡轻易替代。
- [ ] 战斗结束清空未成熟种子，任何跨战斗保留都有明确说明。
- [ ] 没有增加回合开始或回合结束的隐藏自动培育。
- [ ] 稀有度、费用和收益来自机制深度，而不是单纯堆数值。
- [ ] 升级只强化一个主要方向，费用降低没有同时附带大幅数值提升。
- [ ] 升级价值符合普通攻击牌 25% 至 40%、普通防御牌 25% 至 45% 的指导区间，或说明了偏离原因。
- [ ] 先古牌有明确代价和叙事重量。
- [ ] 卡名、形象、元素、效果和文案表达一致主题。
- [ ] 卡面明确区分打出时播种效果（若有）、培养、成熟和离开培养区后的结果。
- [ ] 设计不依赖隐藏规则、未说明顺序或玩家无法理解的连锁。
- [ ] 该卡不会与已有卡牌形成无代价、无限循环或直接替代关系。

## 13. 常见概念问题

- 把种子设计成一种新的卡牌类型。
- 让种子打出后立即自动完成一部分自身需求。
- 因为植物主题，就把所有种子都设计成防御牌或都设计成成长牌。
- 没有播种效果，成熟收益又不足以支撑等待，导致整张卡没有存在理由。
- 播种效果很强，成熟效果又无代价，导致等待没有风险。
- 把“没有播种效果”误判为违反规则，却没有为成熟收益或成长路线提供相应补偿。
- 没有先把效果换算成 `R`，也没有计算 `P`，只凭文字数量和主观感觉判断强度。
- 只看基础 `R`，不考虑费用成本 `C`、阶段倍率、敌人语境和卡组需求。
- 衍生卡只计算自身成本，没有追加生成它的原卡成本。
- 原卡只计算自身价值，没有额外计入衍生卡价值总和的 1/5。
- 生成多张衍生牌时只按一张计算，或没有按价值总和累加。
- 衍生牌继续生成其他牌时，没有沿生成链逐层累加来源成本与 1/5 价值。
- 用“先古、事件或稀有获取”解释所有超额数值，却没有不可复制性和真实机会成本。
- 把模型中心线当作硬上限，删除所有上侧离群卡和低强度功能牌，导致卡牌同质化。
- 用低频条件解释超额数值，却没有验证条件在正常牌组中的实际触发频率。
- 星费或其他特殊资源没有定义价值，却在模型中按免费资源处理。
- 卡牌进入普通生成池后仍保留先古或独占奖励的获取预算系数。
- 用全牌组、全部种子或理论最大数量计算规模价值，而不是使用平均影响数量。
- 稀有牌获得超过预算的无条件收益，或用高稀有度掩盖普通牌也能使用的超模效果。
- 种子的需求、成熟时间和成熟收益不在同一档位。
- 无播种效果时同时降低需求、降低费用并提高成熟收益。
- 0 费牌没有消耗、弃牌、生命代价或严格条件，却拥有完整基础牌强度。
- 升级同时降低费用、增强即时效果和增强成熟效果。
- 第二份和第三份同名牌几乎没有边际损失，持续挤压其他构筑选择。
- 让玩家从培养区中自由选择某一颗种子，使种植顺序失去策略意义。
- 把“第一颗”当成任意点选，而没有明确它是固定的前 1 颗。
- 一张卡同时包揽攻击、防御、抽牌、回能和培育。
- 让万能元素变成普通元素牌，破坏元素路线选择。
- 无条件扩容，使培养区满格的取舍消失。
- 通过隐藏的回合开始或结束效果自动推进成熟。
- 没有种子时，整套牌组完全无法防守或出牌。
- 稀有度主要通过放大数字体现，而不是机制差异。
- 先古牌只是普通卡去掉了所有限制。
- 卡名叫某一植物，效果却与植物特征和元素没有关系。
- 文案没有说明效果发生在打出、培养、成熟还是离开培养区之后；没有播种效果时也没有明确告知玩家打出后不会立即产生收益。

概念设计的目标不仅是让数值落在预算内，还要让玩家能理解它、愿意围绕它构筑，并且在使用过程中感受到植物学家独特的植物学战斗方式。
